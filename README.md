# Esporte Sem Limites

Projeto web com foco no **esporte adaptado**, na inclusão de pessoas com deficiência e no impacto social do esporte.

A página inicial apresenta informações sobre o que é esporte adaptado e destaca a importância da inclusão, da sustentabilidade e dos benefícios sociais relacionados a essa prática.

## 🎯 Objetivo

Compartilhar informações sobre o esporte adaptado e destacar como ele pode contribuir para uma sociedade mais inclusiva e acessível.

## ✨ Conteúdo do projeto

- **Esporte adaptado:** explicação do conceito e exemplos de modalidades.
- **Inclusão:** importância de ampliar a participação e a visibilidade de pessoas com deficiência.
- **Sustentabilidade:** reflexão sobre materiais e equipamentos utilizados no esporte.
- **Impacto social:** destaque para a contribuição de clubes e projetos esportivos para a sociedade.
- **Navegação do site:** menu com links para páginas sobre o projeto, impacto, acessibilidade, galeria, mídia, notícias, orçamento e contato.

> Observação: o arquivo `index.html` disponibilizado contém a página inicial e links para outras páginas. Para que todos os links funcionem, os respectivos arquivos HTML precisam estar presentes no projeto.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura e organização do conteúdo.
- **CSS3** — estilos, cores, espaçamento e apresentação visual.

## 🎨 Identidade visual

O layout utiliza fundo claro, cabeçalho e rodapé em azul-escuro, conteúdo organizado em seções brancas e detalhes em tom coral para destacar elementos.

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Confira se os arquivos `index.html` e `style.css` estão na mesma pasta.
3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências para visualizar a página inicial.

## 📁 Estrutura dos arquivos

```text
esporte-sem-limites/
├── index.html
├── style.css
└── README.md
```

Outras páginas podem ser adicionadas à estrutura conforme o desenvolvimento do projeto.

## ♿ Tema e acessibilidade

O projeto aborda a importância da inclusão no esporte e possui uma seção dedicada à acessibilidade na navegação do site. A acessibilidade completa deve ser verificada e aprimorada com testes específicos, incluindo navegação por teclado, contraste, textos alternativos para imagens e compatibilidade com leitores de tela.
